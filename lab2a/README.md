## 📋 Описание проекта

Программа на языке C# предназначена для статического анализа исходного кода и расчета метрик сложности потока управления по методу Джилба. Анализ выполняется с использованием синтаксических деревьев (Roslyn API), что обеспечивает высокую точность разбора кода.

### Рассчитываемые метрики:
- **CL** (Absolute Complexity) — абсолютная сложность (общее количество условных операторов и ветвлений).
- **cl** (Relative Complexity) — относительная сложность (насыщенность программы условными операторами, рассчитывается как `CL / N`, где N — общее число операторов).
- **CLI** (Maximum Nesting Level) — максимальный уровень вложенности условных операторов.

### Дополнительные возможности:
- Построение таблицы всех ветвлений с указанием номера строки, типа условия и уровня вложенности.
- Построение таблицы использованных операторов языка C# с подсчетом их количества.
- Выявление и вывод синтаксических ошибок в анализируемом коде.
